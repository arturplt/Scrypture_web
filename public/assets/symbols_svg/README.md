# Flight-pattern symbol SVG set

21 independent, transparent, vector SVG icons sampled from the final red-button reference image.
The icon order, facing directions and deliberately uneven spatial grouping are preserved.

- `r01` is the single top zigzag.
- `r02` contains five symbols, left to right.
- `r03` contains nine symbols, left to right.
- `r04` contains three symbols under the middle.
- `r05` contains three symbols at bottom left.
- `all_symbols_original_layout.svg` preserves each symbol's reference-image coordinates.
- `layout_preview_dark.svg` displays them over navy for inspection (not individual button backgrounds).

Each symbol SVG uses a standard 128x128 viewBox, transparent outside the icon. They use `fill=currentColor` with a default warm-ivory foreground declared on the root (`color=#FFF4DB`); change or remove the root `color` attribute to recolour.
